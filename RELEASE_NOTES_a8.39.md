# RELEASE NOTES 1.1.0a8.39

## Ideal Process / Perfect Manipulators
- Theoretical Capacity Report zawiera nową sekcję IDEAL PROCESS / PERFECT MANIPULATORS.
- Nominal process ceiling wynika wyłącznie z technologicznych ograniczeń wanien przy minimalnych nominalnych residence times.
- Possible process ceiling używa Possible Min.
- Model zakłada, że dla każdego transportu natychmiast dostępny jest właściwy manipulator.
- Ignorowane są kolizje, brak mijania, minimalny odstęp, kolejki, rezerwacje i oczekiwanie na manipulator.
- Zachowane są: residence, podnoszenie, obciek źródła, przejazd z zawieszką i opuszczanie.
- Raport pokazuje również idealny czas pełnej drogi jednej zawieszki oraz podział residence / handling.
- Dla każdego przejścia wybierany jest najszybszy manipulator, którego twarda strefa obejmuje źródło i cel.
